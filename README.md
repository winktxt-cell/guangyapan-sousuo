光鸭云盘 - 移动/复制目录快速搜索（Tampermonkey 油猴脚本）
在光鸭云盘（guangyapan.com）的「移动到 / 复制到」弹窗里直接搜索全盘目录，点击结果自动展开目录树并定位到目标文件夹，免去手动一层层翻目录。

功能
弹窗顶部注入搜索框，输入关键词即搜全盘目录（复用站点自带搜索接口，与网页顶部搜索同源同能力）
搜索结果实时展示：文件夹排前、关键词高亮、显示类型与定位按钮
点击「定位」自动逐级展开目录树并选中目标目录；文件自动定位到其父目录
自动捕获站点登录态，无需额外配置
液态玻璃（Liquid Glass）风格 UI：半透明磨砂、模糊、内高光，不遮挡弹窗关闭按钮
守护式注入：弹窗被 React 重渲染后自动重建并恢复搜索状态
安装
安装浏览器扩展 Tampermonkey（脚本猫亦可）
打开脚本文件 guangyapan-sousuo.user.js，Tampermonkey 会弹出安装页，点击「安装」
若已装旧版（v1/v2/v3），请先删除旧版再安装本脚本，避免多版本干扰
使用
打开光鸭云盘（需已登录）
对任意文件执行「移动」或「复制」，弹窗顶部出现搜索框
输入目录关键词（支持部分匹配），下方即时列出匹配目录
点击目标条目右侧「定位」，目录树自动展开并选中目标位置
选中后继续点击弹窗的「移动到 / 复制到」按钮完成操作
快捷键：Esc 清空搜索并收起结果面板。
